# Глоссарий домена

- **sync-data.json** — единый файл состояния SP на WebDAV, префикс `pf_2__`.
- **operation log / recentOps** — журнал операций, через который SP-клиенты применяют чужие изменения.
- **vectorClock** — векторные часы `{clientId: counter}` для определения конфликтов.
- **TODAY** — специальный тег (`id="TODAY"`), исторический механизм Today-вида.
- **planner** — состояние планировщика дней (`days: {YYYY-MM-DD: [taskId]}`).
